# `ed brew upgrade`

[`ed brew`](./README.md)

[The `ed` command line](../README.md)

```bash
ed brew upgrade NAME [--kind formula|cask] [--json]
```

Upgrades one exact formula name by default. Use `--kind cask` for an application cask. The operation is bounded and noninteractive, so packages that require authentication must be handled directly in Terminal.
