# `ed brew ls`

[`ed brew`](./README.md)

[The `ed` command line](../README.md)

```bash
ed brew ls [--kind formula|cask] [--outdated] [--json]
```

Lists installed formulae and casks with installed versions and available updates. `ed brew list` is an alias. Use `--kind` to select one package type and `--outdated` to show only packages with an update.
