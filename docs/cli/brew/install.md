# `ed brew install`

[`ed brew`](./README.md)

[The `ed` command line](../README.md)

```bash
ed brew install NAME [--kind formula|cask] [--json]
```

Installs one exact formula name by default. Use `--kind cask` for an application cask. Edith validates the package token before starting Homebrew and runs the operation noninteractively with fixed time and output limits.
