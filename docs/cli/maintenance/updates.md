# `ed maintenance updates`

[`ed maintenance`](./README.md)

[The `ed` command line](../README.md)

```bash
ed maintenance updates [--json]
```

Discovers Homebrew cask and formula, Mac App Store through `mas`, Sparkle, and standard HTTPS app-feed updates. Human output shows versions, source, and confidence. JSON includes release information, freshness, application identity, action, and the exact command. Discovery never installs anything.
