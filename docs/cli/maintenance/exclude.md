# `ed maintenance exclude`

Stops offering updates for one bundle identifier.

[`ed maintenance`](./README.md)

Usage:

```
ed maintenance exclude <bundle-id> [--json]
```

Examples:

```
ed maintenance exclude com.example.App
ed maintenance exclude com.example.App --json
```
