# `ed seo show`

[`ed seo`](./README.md)

[The `ed` command line](../README.md)

```bash
ed seo show <id> [--json]
```

Reads one project, its latest run summary, and the saved page selection. It does not crawl. Use `ed seo run` for page results. JSON includes `draft.discoveredPageURLs`, `draft.selectedPageURLs`, and `draft.includeLighthouse`.
