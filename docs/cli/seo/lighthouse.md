# `ed seo lighthouse`

[`ed seo`](./README.md)

[The `ed` command line](../README.md)

```bash
ed seo lighthouse <id> <on|off> [--json]
```

Writes the include-Lighthouse switch used by the next audit. It does not start one. `on` asks for scores. `off` records metadata only. `ed seo start --lighthouse` or `--no-lighthouse` overrides this for a single run.
