# `ed attention backup`

Uploads the attention library to iCloud.

[`ed attention`](./README.md)

Usage:

```
ed attention backup [--json]
```

This asks the background agent for the same backup Attention settings run.

Examples:

```
ed attention backup
ed attention backup --json
```
