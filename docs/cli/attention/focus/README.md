# `ed attention focus`

Starts, inspects, or finishes a local focus session. Sessions persist on disk and
work whether Edith's main window is open or closed.

## Commands

- [`ed attention focus status`](./status.md)
- [`ed attention focus start`](./start.md)
- [`ed attention focus stop`](./stop.md)

A bare `ed attention focus` runs `status`.
