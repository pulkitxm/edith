# `ed attention restore`

Restores the attention library from iCloud.

[`ed attention`](./README.md)

Usage:

```
ed attention restore [--yes] [--json]
```

Without `--yes` this prints the plan. `--yes` asks the agent to replace local attention data from the backup.

Examples:

```
ed attention restore
ed attention restore --yes
```
