# `ed attention rules`

Export and import complete attention rules and categories. Rules can match apps,
domains, URL prefixes, title keywords, context tags and browser profile labels.
Your configuration applies to existing history as well as future activity.

## Commands

- [`ed attention rules export`](./export.md)
- [`ed attention rules import`](./import.md)
