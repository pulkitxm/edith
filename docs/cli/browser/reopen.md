# `ed browser reopen`

Reopens the most recently closed notch browser tab.

[`ed browser`](./README.md)

Usage:

```
ed browser reopen [--json]
```

Options:

| Name | Type / values | Default | What it does |
| --- | --- | --- | --- |
| `--json` | flag | off | Emits one JSON document on stdout. |

Opens the last closed address again.

Examples:

```
ed browser reopen
ed browser reopen --json
```
