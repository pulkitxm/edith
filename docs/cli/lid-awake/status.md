# `ed lid-awake status`

Prints the current Lid Awake state, including the session, remaining time,
battery policy, extension state and helper status. It can read the stored state
while Edith is closed, and accepts `--json` for a stable object.

```
ed lid-awake status
ed lid-awake status --json
```

Use `ed lid-awake on` and `ed lid-awake off` to change the live power state.
