# `ed emoji forget`

Forgets one frequently used emoji.

[`ed emoji`](./README.md)

Usage:

```
ed emoji forget <emoji> [--json]
```

The argument is a character, a name, or a code point, the same as `ed emoji insert`. Other ledger entries stay.

Examples:

```
ed emoji forget 1F600
ed emoji forget 1F600 --json
```
