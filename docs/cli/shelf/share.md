# `ed shelf share`

Asks the running notch shelf to open its anchored macOS share picker for one
numbered item.

```text
ed shelf share <n> [--json]
```

JSON reports `action`, `index`, `id`, `name`, `path`, and `requested`. Exit 4
means Edith is not running or the Notch Shelf extension is off.
