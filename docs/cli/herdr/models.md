# `ed herdr models`

Lists the models, effort levels and fast mode each agent kind offers when Edith
starts it.

```
ed herdr models [<kind>] [--machine <name>] [--refresh] [--json]
```

## Arguments

| Name | Type / values | Default | What it does |
| --- | --- | --- | --- |
| `<kind>` | `claude`, `codex`, `opencode`, `cursor`, `pi`, `gemini`, `amp`, or the display name such as `"Claude Code"` | every kind | Only this agent kind |

## Options

| Name | Type / values | Default | What it does |
| --- | --- | --- | --- |
| `--machine <name>` | machine name, alias, UUID, unique prefix, or `local` | this Mac | Ask the CLIs installed on this machine over SSH |
| `--refresh` | flag | off | Ask the CLI again; for Codex this also refreshes its catalog from the network |
| `--json` | flag | off | Emit JSON on stdout |

`--help` is generated by the parser, prints the usage summary on stdout and
exits 0.

## Where the lists come from

| Kind | Source | Launch flags |
| --- | --- | --- |
| Codex | `~/.codex/models_cache.json`, else `codex debug models --bundled`; `--refresh` runs `codex debug models` | `-m`, `-c model_reasoning_effort="<level>"`, `-c service_tier="fast"` |
| OpenCode | `opencode models` under a pseudo terminal | none, the TUI takes no model flag |
| Pi | `pi --list-models` | `--model`, `--thinking` |
| Cursor Agent | `cursor-agent models`, else `agent models` | `--model` |
| Claude Code | built in aliases and model ids | `--model`, `--effort`, `--settings '{"fastMode":true}'` |
| Gemini | built in aliases | `-m` |
| Amp | built in modes | `--mode` |

A CLI that is missing, slow (8 seconds, 20 with `--refresh`) or prints
something unreadable falls back to the built in list, and `source` says
`built in`. Codex only lists models whose catalog visibility is `list`, in
catalog priority order, and offers fast mode only when the model advertises a
fast service tier. Windows machines always use the built in lists.

## `--json` shape

```json
{
  "kinds": [
    {
      "defaultEfforts": [{ "id": "low", "summary": "Fast responses with lighter reasoning" }],
      "defaultFast": "2x speed, increased usage",
      "kind": "Codex",
      "live": true,
      "models": [
        {
          "defaultEffort": "medium",
          "efforts": [{ "id": "low", "summary": "Fast responses with lighter reasoning" }],
          "fast": true,
          "fastSummary": "1.5x speed",
          "id": "gpt-6-sol",
          "name": "GPT-6-Sol",
          "summary": "Workhorse model for coding and everyday work."
        }
      ],
      "note": null,
      "selectsAtLaunch": true,
      "source": "from codex"
    }
  ]
}
```

`defaultEfforts` and `defaultFast` apply when no model is chosen, or when the
chosen model is not in the list. `selectsAtLaunch` is false for OpenCode.

The human form prints one table per kind, `MODEL`, `EFFORT`, `FAST`, `ABOUT`,
with a `(default)` row first. A kind with no options, such as `copilot`, exits 3.
