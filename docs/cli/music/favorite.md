# `ed music favorite`

Adds a resolved library track to favourites. Repeating the command succeeds
without duplicating the entry.

```text
ed music favorite <track> [--json]
ed music favourite <track> [--json]
```

JSON reports `action`, `path`, `title`, `favourite`, and `changed`.
