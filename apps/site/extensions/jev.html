Jev

Faster, smarter decisions behind Edith's smart features.

LabsLabs
$ed extensions install jev
Get Edith

Overview

Jev is a fast decision service from TypeSafe. With your own API key saved, Edith uses it for agent attention, docs search, usage matching and alerts. Without a key, every feature keeps working with its built-in rules.

How it works

  1. 1

    Get a TypeSafe key

    Create an API key at console.typesafe.ai. It is optional.

  2. 2

    Save it in Edith

    Paste the key into settings. It is stored in your Keychain on this Mac.

  3. 3

    Check the key

    Run a tiny test to confirm it works and has credits.

From the terminal

Every example returns JSON with --json, and agents can call the same thing over MCP.

$ ed jev status
$ ed jev status --probe
$ ed jev key show
ed jev reference
