Agents

See every coding agent on your Macs in one board, and step in when one needs you.

Agents & Terminal
$ed extensions install herdr
Get Edith

Overview

Agents shows the coding agents running in Herdr on this Mac and your SSH machines, grouped by what they are doing. Open any agent to watch or type to it, start new ones, and get told when one is blocked. Nothing runs until you start it.

How it works

  1. 1

    Find your agents

    Edith looks for the herdr command on this Mac and your SSH machines and lists every live session.

  2. 2

    Start an agent

    Press New Agent, then choose a coding agent, a machine and a space. It opens in its own pane.

  3. 3

    Watch the board

    Agents are grouped as blocked, working, done or idle so you see who needs you.

  4. 4

    Step in

    Open an agent to read its terminal, answer a question, or send it a message.

From the terminal

Every example returns JSON with --json, and agents can call the same thing over MCP.

$ ed herdr ls
$ ed herdr models
$ ed herdr defaults ls
$ ed herdr layout ls
ed herdr reference
