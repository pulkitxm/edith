Presenter

Blur private details in Edith while you share your screen.

Mac Utilities⌥⇧⌘P
$ed extensions install presenter
Get Edith

Overview

Presenter hides things like music, cost figures, calendar events and agents inside Edith while you present or record. It can turn on by itself when it sees screen sharing, or you switch it by hand with a shortcut. Turn it off and everything is shown again.

  • Blurs spend figures, track names, calendar entries and agents.
  • Turns on by itself when it detects a screen share.

How it works

  1. 1

    Choose what to blur

    Pick the kinds of private details to hide in Presenter settings.

  2. 2

    Let it detect sharing

    Turn on auto detection and it blurs when a screen share or recording starts.

  3. 3

    Force it on or off

    Use the shortcut or the Presenter card any time, for example when detection guesses wrong.

From the terminal

Every example returns JSON with --json, and agents can call the same thing over MCP.

$ ed presenter status
$ ed presenter start
$ ed presenter stop
ed presenter reference
