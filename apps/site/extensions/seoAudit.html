Site Audit

Find SEO problems on your website, page by page.

Developer & Data
$ed extensions install seoAudit
Get Edith

Overview

Add your site's address and Edith lists its pages from the sitemap, then checks titles, descriptions, headings and share cards. Add Lighthouse for performance scores. Reports are saved on this Mac so you can compare runs. Your site is only read, never changed.

How it works

  1. 1

    Add your site

    Enter a URL like example.com or localhost:3000.

  2. 2

    Find pages

    Edith reads your sitemap and lists what it finds.

  3. 3

    Choose and run

    Pick the pages to check and start the audit.

  4. 4

    Read the report

    Open a page to see its issues and how it looks when shared.

From the terminal

Every example returns JSON with --json, and agents can call the same thing over MCP.

$ ed seo create https://example.com --name Example --json
$ ed seo start PROJECT --json
$ ed seo ls --json
$ ed seo pages PROJECT --json
ed seo reference
