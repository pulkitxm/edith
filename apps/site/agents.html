Agents and MCP

Give your coding agents a whole Mac toolkit.

Edith speaks MCP. Connect Claude Code, Codex, Cursor or VS Code once, and every Edith command becomes a tool your agent can call, with the same safety rules as the command line.

$ed mcp install --client all
1

Connect

Run ed mcp install --client all, or press Connect all in Settings, then Agents. Edith finds every client on your Mac.

2

Discover

The agent calls edith_catalog to see each extension, whether it is installed, and example commands.

3

Act

It calls tools like edith_usage_limits or edith_studio_pdf_merge and gets the command's JSON back.

Safe by default

Agents preview before they change anything.

Commands that change or remove something return a preview until the call passes confirm. A call that slips --yes into its arguments is refused, so confirm is the only way to apply.

  • Tools exist only for extensions you have enabled.
  • Installing an extension asks first, then the tool list refreshes.
  • Every tool returns the same JSON as ed ... --json.
agent  edith_catalog {"query": "pdf"}
edith  studio · installed · 108 tools
agent  edith_studio_pdf_merge {"arguments": ["a.pdf", "b.pdf"]}
edith  {"output": "merged.pdf", "pages": 14}
agent  edith_usage_limits {"arguments": ["--refresh"]}
edith  {"claude": {"session": 0.42, "weekly": 0.18}}

Clients

Works with the agents you already use.

Use the one-step installer, or register Edith yourself.

Claude Code

$claude mcp add --scope user edith -- /Applications/Edith.app/Contents/MacOS/ed mcp

Codex

$codex mcp add edith -- /Applications/Edith.app/Contents/MacOS/ed mcp

Cursor

$ed mcp install --client cursor

VS Code

$ed mcp install --client vscode

Usage See what your coding agents cost and how close you are to their limits. Machines Watch, browse and run your servers and containers from one place. Agents See every coding agent on your Macs in one board, and step in when one needs you. Code Review Review pull requests and code changes in a focused terminal workspace.

Command line

Everything is scriptable.

The bundled ed command talks to the running app. Results are JSON, errors are JSON on stderr, and exit codes are stable.

$ ed extensions install clipboard
$ ed clipboard ls --category link --limit 5
$ ed usage summary --json
$ ed machines ls
$ ed studio edit render cut.openscreen --output delivery.mp4
