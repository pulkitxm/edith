Homebrew

Taps, installs the app and puts ed and edith on your PATH.

$brew install --cask pulkitxm/tap/edith

Edith updates itself. To force Homebrew, run brew upgrade --cask --greedy edith.

Requirements

What you need.

macOS 14 or later

Sonoma, Sequoia and newer. Audio Mixer needs macOS 14.4.

Apple silicon

M1 or newer. Intel Macs are not supported.

A little space

The app is small. Extensions download only when you install them.

First launch

Up and running in a minute.

  1. 1

    Open Edith

    It lives in your menu bar. Press ⌥⌘E to open the panel from anywhere.

  2. 2

    Pick your extensions

    Onboarding suggests a starter set. Add or remove any of them later from Extensions.

  3. 3

    Grant only what you use

    macOS asks for permissions such as Screen Recording or Accessibility only when an extension needs them.

  4. 4

    Connect your agents

    Optional. Run ed mcp install --client all or use Settings, then Agents.

Uninstall

Leaving is easy too.

Quit Edith and move it to the Trash, or remove it with Homebrew. ed uninstall also removes the command line tools it installed.

$brew uninstall --cask edith
