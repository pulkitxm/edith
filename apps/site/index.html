Usage

Know exactly what your coding agents cost.

Usage reads the history Claude Code, Codex and pi already keep on your Mac and turns it into tokens, cost and limits by day, model, project and machine.

  • Claude Code, Codex and pi activity attributed to the right machine, repository, worktree and chat.
  • Claude, Codex and Cursor rate limits as live rings with countdowns and history.
  • A menu bar readout with compact or roomy layouts and a time-aware risk tint.
  • Threshold, ahead-of-pace, burning-hot, back-to-green and pre-reset alerts, all optional.

Studio

Every file tool. Offline.

Stop uploading private documents to PDF websites. Studio has 108 tools for PDFs, images, video and audio, and every one runs on your Mac.

  • Merge, split, sign, redact, compress and convert PDFs.
  • Remove image backgrounds, resize, convert and compress images.
  • Compress and convert video and audio, or cut a video on a timeline.
  • Everything runs on this Mac. Nothing is uploaded.

Agents and MCP

Your agents can use Edith too.

One command connects Claude Code, Codex, Cursor and VS Code. Every ed command becomes an MCP tool, so an agent can check your limits, convert a file or restart a container for you.

How agents use Edith 
$ ed mcp install --client all
claude  created   ~/.claude.json
codex   created   ~/.codex/config.toml
cursor  created   ~/.cursor/mcp.json
Restart the client, then ask it to call edith_catalog.
